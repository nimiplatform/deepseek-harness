# Release 0.2.2

First public Nimi Catalog and hosted Web release of Nimi DSH (adapted from upstream DeepSeek Harness `0.2.2-rc.3`).

- Adds native Windows x64 and macOS arm64 `.nimiapp` packages managed by Nimi Home, connecting DeepSeek Harness sessions to Nimi Home AI models, integrations, Home Activity, and account-partitioned local storage.
- Includes the Nimi DSH Remote Web Companion (`ai.nimi.dsh.sessions`) for creating or resuming desktop sessions, approving file and tool actions, and transferring workspace files up to 32 MiB.
- Switches all Nimi SDK, Kit, and App Tools dependencies to public npm packages (`@nimiplatform/sdk@0.24.0-rc.10`, `@nimiplatform/kit@0.24.0-rc.16`, `@nimiplatform/app-tools@0.16.0-rc.12`) and adds bilingual storefront metadata.
